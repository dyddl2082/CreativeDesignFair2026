# MacRobot Object Finder Stage

이 번들은 기존 D435 depth-candidate + candidate filter + DINOv2 retrieval + temporal confirmation을 `/object_finder/goal`과 `/object_finder/result` 계약으로 묶는 `macrobot_object_finder` 패키지를 설치한다.

```bash
chmod +x install_object_finder_stage.sh
./install_object_finder_stage.sh ~/MacRobot
```

설치 후 `macrobot_object_finder/README.md`를 확인한다.
