# Validation artifacts

- `VALIDATION_REPORT.json`: structural, transform, direction, YAML-type, and mesh checks
- `KINEMATIC_SANITY_SAMPLES.csv`: q1/q2 finite-motion reference points
- `GRIPPER_DIRECTION_SAMPLES.csv`: q3 closing and gear-ratio reference
- `COLLISION_MESH_MANIFEST.csv`: exact collision STL counts and hashes
- `VISUAL_MESH_MANIFEST.csv`: source DAE hashes
- `R3_TO_R4_DELTA.json`: previous-to-current model changes
